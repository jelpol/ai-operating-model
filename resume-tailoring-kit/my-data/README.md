# my-data (private)

Your fact registry, career thesis, and session notes live here. This folder is gitignored on purpose: nothing you put in it should ever reach a public repository.

1. Copy `../templates/fact_registry_template.json` here as `fact_registry.json`.
2. Copy `../templates/career_thesis_template.md` here as `career_thesis.md`.
3. Optionally keep a running `lessons_learned.md` for what works and fails across your applications.
