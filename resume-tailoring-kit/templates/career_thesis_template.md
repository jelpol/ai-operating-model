# Career Thesis Worksheet

Copy this file to `my-data/career_thesis.md` and fill it in before your first build session. The pipeline's qualification module (13) reads this to tell you which jobs deserve your effort. Ten honest minutes here saves whole evenings later.

**Version:** 1.0 (public starter kit release)

## How the pipeline uses this

Module 13 classifies every job posting against your paths: which path it serves, whether it advances or stalls you, and pursue / hold / do-not-pursue. A do-not-pursue verdict is the system protecting your time. Override it when you know something the file does not, then update the file so it knows next time.
